# Curso de HTML — Exercícios e Anotações

Repositório de estudos práticos de HTML5, com exercícios organizados por tópico, seguindo boas práticas de semântica, acessibilidade e SEO.

## Estrutura

Cada pasta representa um tópico do curso, numerada em ordem de aprendizado:

- `01-estrutura-basica` - estrutura HTML5, meta tags, SEO
- `02-titulos-e-paragrafos` - hierarquia de títulos (h1 a h6) e parágrafos
- `03-tags-sem-conteudo` - hr, br, img
- `04-comentarios` - como e quando comentar código
